# WMS_Demo
demo網址: https://hongshihjhe.github.io/WMS_Demo

目前僅示範收貨、調撥和查詢功能，登入帳密: admin/admin，登入帳密參考目錄下的login.json，帳號角色參考userRole.json

管理者角色可以進入權限管理頁面，設定帳號權限和角色權限，權限優先級: 帳號權限>角色權限

若使用者無此功能權限，該功能會在畫面上隱藏，如果直接透過url進入會擋住並跳出"沒有權限"訊息

## 功能簡介
胚布收貨
  1. 胚布點收: 掃描單號，確認單號上的胚布資料並收到載體上
  2. 上架作業: 掃描載體，取得載體上已點收未上架的胚布資料後更新其倉庫儲位
  3. 已點收位上架: 查詢已點收未上架的胚布資料
     
調撥
  1. 胚布調撥: 透過載體以及設定的載體儲位進行調撥，更新胚布的倉庫儲位
  2. 載體更換: 更換胚布的載體
  3. 載體移轉: 將載體上的胚布調撥並設定載體的儲位
  4. 載體綁定: 設定載體的儲位

查詢
  1. 載體查詢: 查詢載體上有哪些胚布
  2. 製造批號或布疋號查詢: 查詢胚布在哪個載體上
